===== autoeq --help =====
AutoEQ objectives, constraints, and optimizer backends

Usage: autoeq [OPTIONS]

Options:
  -V, --program-version
          Print the installed program's package version and exit

  -n, --num-filters <NUM_FILTERS>
          Number of IIR filters to use for optimization
          
          [default: 7]

  -c, --curve <CURVE>
          Path to the input curve CSV file (format: frequency,spl). Required unless speaker, version, and measurement are provided for API data

  -t, --target <TARGET>
          Path to the optional target curve CSV file (format: frequency,spl). If not provided, a flat 0 dB target is assumed

      --product-config <PATH>
          Product workflow JSON describing source, independent target support, and an explicit playback device profile

      --product-renderer-capabilities
          Print the versioned product-renderer capability report as JSON and exit. This query must be used alone; it does not load measurements or devices

  -s, --sample-rate <SAMPLE_RATE>
          The sample rate for the IIR filters
          
          [default: 48000]

      --max-db <MAX_DB>
          Maximum absolute dB gain allowed for each filter
          
          [default: 3]

      --min-db <MIN_DB>
          Minimum signed dB gain allowed for each filter (the cut bound)
          
          [default: -12]

      --max-q <MAX_Q>
          Maximum Q factor allowed for each filter
          
          [default: 3]

      --min-q <MIN_Q>
          Minimum Q factor allowed for each filter
          
          [default: 1]

      --min-freq <MIN_FREQ>
          Minimum frequency allowed for each filter
          
          [default: 60]

      --max-freq <MAX_FREQ>
          Maximum frequency allowed for each filter
          
          [default: 16000]

  -o, --output <OUTPUT>
          Output PNG file for plotting results

      --speaker <SPEAKER>
          Speaker name for API data fetching

      --version <VERSION>
          Version for API data fetching

      --measurement <MEASUREMENT>
          Measurement type for API data fetching

      --curve-name <CURVE_NAME>
          Curve name inside CEA2034 plots to use (only when --measurement CEA2034) e.g., "Listening Window", "On Axis", "Early Reflections". Default: Listening Window
          
          [default: "Listening Window"]

      --algo <ALGO>
          Optimization algorithm to use (e.g., autoeq:isres, autoeq:cobyla)
          
          [default: autoeq:cobyla]

      --population <POPULATION>
          Optional population size for population-based algorithms (e.g., ISRES)
          
          [default: 300]

      --maxeval <MAXEVAL>
          Maximum number of evaluations for the optimizer
          
          [default: 2000]

      --resume-state <PATH>
          Load a checked warm-start candidate from this checkpoint file

      --checkpoint-state <PATH>
          Atomically save a recoverable warm-start checkpoint to this file

      --resume-exact <PATH>
          Resume the complete seeded AutoEQ DE optimizer state from this file. Exact continuation requires the same measurement, config, seed, executable, and numeric runtime environment

      --checkpoint-exact <PATH>
          Atomically save complete AutoEQ DE state after each safe generation barrier

      --refine
          Whether to run a local refinement after global optimization

      --local-algo <LOCAL_ALGO>
          Local optimizer to use for refinement (e.g., cobyla)
          
          [default: cobyla]

      --bo-initial-samples <BO_INITIAL_SAMPLES>
          Bayesian optimization Sobol hot-start samples (0 = automatic)
          
          [default: 0]

      --bo-batch-size <BO_BATCH_SIZE>
          Bayesian optimization batch size for parallel expensive evaluations (0 = automatic)
          
          [default: 0]

      --bo-posterior-std-threshold <BO_POSTERIOR_STD_THRESHOLD>
          Bayesian optimization posterior-std threshold for local-refiner handoff (0 disables)
          
          [default: 0]

      --bo-acquisition <BO_ACQUISITION>
          Bayesian optimization acquisition: ei, qei, or thompson
          
          [default: qei]

      --bo-ehvi
          Use Monte-Carlo qEHVI Bayesian optimization for multi-objective data

      --min-spacing-oct <MIN_SPACING_OCT>
          Minimum spacing between filter center frequencies in octaves (0 disables)
          
          [default: 0.2]

      --spacing-weight <SPACING_WEIGHT>
          Weight for the spacing penalty in the objective function
          
          [default: 20]

      --smoothness-weight <SMOOTHNESS_WEIGHT>
          Second-difference penalty weight on the correction curve (dB/decade^2). 0 disables. Suggested starting point: 0.05
          
          [default: 0]

      --smoothness-exponent <SMOOTHNESS_EXPONENT>
          L_p exponent for smoothness penalty (1.0 = TV^2/sparsifier, 2.0 = L2)
          
          [default: 1]

      --smoothness-schroeder-hz <SMOOTHNESS_SCHROEDER_HZ>
          Schroeder cutoff for relaxed smoothness in the modal region

      --smoothness-modal-scale <SMOOTHNESS_MODAL_SCALE>
          Modal-region weight multiplier (0 = exempt modal region entirely)
          
          [default: 0.1]

      --smooth
          Enable smoothing (regularization) of the inverted target curve

      --smooth-n <SMOOTH_N>
          Smoothing level as 1/N octave (N in [1..24]). Example: N=6 => 1/6 octave smoothing
          
          [default: 2]

      --loss <LOSS>
          Loss function to optimize (flat or score)

          Possible values:
          - speaker-flat:            Flat loss function (minimize deviation from target curve)
          - speaker-flat-asymmetric: Flat loss with asymmetric weighting (peaks penalized 2x more than dips) Use this for room correction where nulls cannot be fixed with EQ
          - speaker-score:           Harman/Olive preference-score objective
          - headphone-flat:          Flat loss function (minimize deviation from target curve)
          - headphone-score:         Harman headphone preference-score objective
          - drivers-flat:            Multi-driver crossover optimization (flatten combined response)
          - multi-sub-flat:          Multi-subwoofer optimization (flatten summed response)
          - epa:                     EPA (Evaluation, Potency, Activity) perceptual loss. Combines spectral flatness with sharpness, roughness, and loudness balance penalties derived from Zwicker psychoacoustic metrics
          
          [default: speaker-flat]

      --peq-model <PEQ_MODEL>
          PEQ model that defines the filter structure
          
          [default: pk]
          [possible values: pk, hp-pk, hp-pk-lp, ls-pk, ls-pk-hs, pk-ls-hs, free-pk-free, free]

      --peq-model-list
          Display list of available PEQ models with descriptions and exit

      --algo-list
          Display list of available optimization algorithms with descriptions and exit

      --tolerance <TOLERANCE>
          Optimization tolerance (tol parameter for DE algorithm)
          
          [default: 0.001]

      --atolerance <ATOLERANCE>
          Absolute tolerance (atol parameter for DE algorithm)
          
          [default: 0.0001]

      --recombination <RECOMBINATION>
          Recombination probability for DE algorithm (0.0 to 1.0)
          
          [default: 0.9]

      --strategy <STRATEGY>
          DE strategy to use (e.g., best1bin, rand1bin, currenttobest1bin, adaptive)
          
          [default: currenttobest1bin]

      --strategy-list
          Display list of available DE strategies and exit

      --adaptive-weight-f <ADAPTIVE_WEIGHT_F>
          Adaptive weight for F parameter (DE adaptive strategies only)
          
          [default: 0.9]

      --adaptive-weight-cr <ADAPTIVE_WEIGHT_CR>
          Adaptive weight for CR parameter (DE adaptive strategies only)
          
          [default: 0.9]

      --no-parallel
          Disable parallel evaluation for DE algorithm (default: parallel is enabled)

      --parallel-threads <PARALLEL_THREADS>
          Number of threads to use for parallel evaluation (0 = use all available cores)
          
          [default: 0]

      --seed <SEED>
          Random seed for deterministic optimization (default: random seed for each run) Setting this makes optimization results reproducible

      --qa [<THRESHOLD>]
          Quality assurance mode with optional threshold: suppress normal output, show summary line and analysis Bare `--qa` requires strict improvement at threshold zero, convergence, and spacing. A supplied threshold (e.g., `--qa 0.4`) keeps the same strict predicate

      --driver1 <DRIVER1>
          Path to first driver measurement CSV file (for multi-driver optimization with --loss drivers-flat)

      --driver2 <DRIVER2>
          Path to second driver measurement CSV file (for multi-driver optimization with --loss drivers-flat)

      --driver3 <DRIVER3>
          Path to third driver measurement CSV file (for multi-driver optimization with --loss drivers-flat)

      --driver4 <DRIVER4>
          Path to fourth driver measurement CSV file (for multi-driver optimization with --loss drivers-flat)

      --crossover-type <CROSSOVER_TYPE>
          Crossover type for multi-driver optimization (butterworth2, linkwitzriley2, linkwitzriley4)
          
          [default: linkwitzriley4]

      --preset <PRESET>
          Use a named preset that sets all optimizer parameters at once. Available presets: quick, balanced, max-quality, score (speakers only). Individual parameter flags override preset values when both are specified

  -h, --help
          Print help (see a summary with '-h')

Available Optimization Algorithms
=================================

🧬 Metaheuristics Library Algorithms:
   Nature-inspired global optimization (penalty-based constraints)

   - mh:de                | Differential Evolution (robust, good convergence)
   - mh:pso               | Particle Swarm Optimization (fast exploration)
   - mh:rga               | Real-coded Genetic Algorithm (diverse search)
   - mh:tlbo              | Teaching-Learning-Based Optimization (parameter-free)
   - mh:firefly           | Firefly Algorithm (multi-modal problems)

🎵 AutoEQ Custom Algorithms:
   Specialized algorithms developed for audio filter optimization

   - autoeq:cobyla        | Constraints: ✅ Nonlinear | Pure-Rust constrained local optimization
   - autoeq:cobra         | Constraints: ✅ Nonlinear
   - autoeq:isres         | Constraints: ✅ Nonlinear | Pure-Rust stochastic constrained global optimization
   - autoeq:cmaes         | Constraints: ❌ Penalty-based | Covariance Matrix Adaptation Evolution Strategy
   - autoeq:bo            | Constraints: ❌ Penalty-based | Gaussian-process Bayesian optimization
   - autoeq:nsga2         | Constraints: ❌ Penalty-based | NSGA-II multi-objective optimization
   - autoeq:nsga3         | Constraints: ❌ Penalty-based | NSGA-III many-objective optimization
   - autoeq:de            | Constraints: ✅ Nonlinear | Adaptive Differential Evolution with constraint handling

Deprecated NLopt compatibility aliases:
   nlopt:cobyla, nlopt:slsqp, nlopt:bobyqa, nlopt:neldermead, nlopt:sbplx
      → autoeq:cobyla
   nlopt:isres, nlopt:ags, nlopt:origdirect
      → autoeq:isres
   nlopt:crs2lm, nlopt:direct, nlopt:directl, nlopt:gmlsl,
   nlopt:gmlsllds, nlopt:stogo, nlopt:stogorand
      → autoeq:de
   These names are migration aliases, not separate available backends.
